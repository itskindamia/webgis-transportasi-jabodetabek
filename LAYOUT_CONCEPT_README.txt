WEBGIS LAYOUT CONCEPT — 15 September 2026

Visual prototype based on WebGIS_20260914_1_K01-K10_Rail_Fixed.zip.
No transport network data has been intentionally changed.

Layout concept:
- >=1600 px: left workspace 304 px + right utility/info 312 px.
- 761–1599 px: left workspace + compact utility rail on the right.
- Search/legend on medium desktop open as flyouts from the utility rail.
- <761 px: existing hardened mobile/bottom-sheet layout is retained.
- On wide desktop, selecting one route automatically collapses legend sections.

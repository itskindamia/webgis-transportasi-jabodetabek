# D3.2 · Tampilan informasi stasiun desktop

Di desktop (≥1024 px), buka **Peta dasar → Tampilan informasi** untuk memilih **Popup di peta** atau **Panel kanan**. Popup adalah pilihan awal. Aksi **Tampilkan di panel** pada popup mengubah pilihan dan memindahkan fokus ke tab **Terpilih**. Pilihan disimpan di browser. Permalink tetap memakai rute serta ID halte/stasiun.

Mode Popup membiarkan tab dan visibilitas Detail mengikuti pengguna ketika sebuah titik dipilih. Mode Panel memakai tab Terpilih yang sama dan mengambil konten dari popup yang terikat ke marker. Tombol lin, integrasi, arah, serta Sebelumnya/Berikutnya memakai handler dan data jaringan yang sama. Menutup Detail di mode Panel mempertahankan stasiun terpilih. Klik titik membuka Detail kembali.

## QA dan publikasi

Tes D3.2 mencakup penyimpanan preferensi, dua cabang pada Cawang, kontrol keyboard, klik marker dan daftar, navigasi, integrasi eksplisit ke MRT, penutupan Detail, dan pemulihan permalink. Perpindahan ke tablet mengembalikan popup biasa dan desktop mengambil pilihan tersimpan kembali. Uji menghitung event `popupopen` untuk memeriksa bahwa pemilihan, navigasi dan integrasi dalam mode Panel menghasilkan nol popup stasiun.

Penyesuaian pada tes D3 dan tes layout Tabler mencerminkan perilaku baru mode Popup yang mempertahankan tab Detail. Pemeriksaan posisi, data, seleksi, integrasi dan navigasi tetap berlaku. Berkas tes untuk 13 kegagalan historis dipertahankan. [Audit terpisah untuk blocker rilis](d3-2-release-audit.md)

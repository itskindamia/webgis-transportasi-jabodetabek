## Refinement akhir

Landscape 568×320 dan 844×390 memakai header di kolom kiri dan pelayanan/
integrasi/tindakan/navigasi di kolom kanan, dengan satu area scroll. Informasi
pelayanan terlihat pada tampilan awal. Panel detail tablet memberi ruang kepada
popup dan dapat dibuka kembali tanpa menghapus seleksi/tab/URL. Tidak ada gesture
baru yang mengambil alih pan/zoom peta.

Padding vertikal portrait dikurangi, padding legacy berlebih pada root popup
dihilangkan, kartu lin diringkas, dan petunjuk scroll ditampilkan. Status,
struktur, kode stasiun, seluruh integrasi/sumber, Maps dan navigasi tetap tersedia.
PT Sans 400/700 dan tombol posisi Ringkas/Sedang/Penuh dipertahankan.

`getStopPopupOptions` tetap memakai batas bawah 64 px untuk kondisi ekstrem;
menaikkan minimum secara tetap dapat membuat popup keluar dari peta. Pada
landscape normal, padding yang tidak lagi ditempati panel dilepas, lebar popup
ditambah sesuai ruang aktual dan margin frame disesuaikan. Kontrol/atribusi
tetap disisakan ruang. Pengujian mengukur tinggi scroll minimal 90 px, pelayanan
yang terlihat minimal 40 px dan keterjangkauan semua tindakan.

URL stylesheet/script aplikasi memakai `release-20261106-1`. URL WOFF2 tetap sama
karena byte font tidak berubah; preload regular dan CSS menggunakan URL identik.
Tidak ada dependensi/library baru. Tidak ada perubahan pada delapan file yang
dilindungi: empat GeoJSON, `js/map.js`, `js/layout-concept.js`, `css/style.css`
dan `css/layout-concept.css`.

## Verifikasi publikasi

GitHub Pages menggunakan source `main` pada `/`, build type `legacy`, tanpa
perubahan URL/domain. Workflow PR #3 pertama berhasil build/upload tetapi
deployment berhenti pada `updating_pages` lalu timeout 10 menit. Job deployment
yang gagal diulang; status akhir dicatat di PR #4 bersama status rilis final.
Tidak ada layanan Cloudflare yang dibuat; deployment GitHub yang ditemukan
hanya environment `github-pages`.

`tools/smoke-live.mjs` mengambil seluruh respons situs produksi/CDN yang
sesungguhnya melalui proxy runtime. Python memverifikasi TLS dengan CA runtime
karena Chromium tidak mengenali CA proxy secara langsung. Tidak ada stub aset,
data atau tile dalam smoke test ini. Respons lokal situs dibandingkan checksum-nya
dengan kandidat yang diuji; error/404, empat GeoJSON, PT Sans, popup kedua operator,
lin ganda, navigasi dan landscape diperiksa. Jalankan setelah workflow sukses:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node tools/smoke-live.mjs
```

Perangkat fisik dan Safari iOS belum tersedia. Simulasi keyboard/resize Chromium
bukan klaim pengujian perangkat; performa pan/zoom bukan benchmark FPS.

## Rollback

Backup menyimpan tree produksi sebelumnya. Jika rollback diperlukan, buat branch
dari main terbaru, revert merge PR #4 dengan parent pertama, lalu revert merge
PR #3 dengan parent pertama. Buat commit rollback dan publikasikan melalui main
tanpa force-push. Periksa tree terhadap backup sebelum publikasi:

```sh
git fetch origin
git switch -c rollback/ui-20261106 origin/main
git revert --no-commit -m 1 <SHA_MERGE_PR4>
git revert --no-commit -m 1 ba838579eacd24f20301205e3f404910be96a5bc
git diff --cached origin/backup/production-20261106-10abd9e
git commit -m "revert: restore UI before release 20261106"
git push -u origin rollback/ui-20261106
```

Diff terhadap backup harus kosong jika tidak ada perubahan main lain setelah
rilis ini. Setelah rollback digabung ke main, tunggu workflow Pages sukses dan
verifikasi ulang situs live. Prosedur ini hanya didokumentasikan, tidak dijalankan.

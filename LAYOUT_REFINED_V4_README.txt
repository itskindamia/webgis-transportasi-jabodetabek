WebGIS Layout Refined V4 — 15 September 2026

Final layout polish based on V3.

Changes:
- Selected-route left workspace is slightly more compact so the stop list gets more usable height.
- Medium desktop left workspace widened slightly for route names/metadata.
- Utility rail is smaller/lighter and flyouts align to it.
- Route auto-fit now uses tighter screen padding plus adaptive geographic padding for short/medium/long routes.
- A delayed second fit is triggered after the adaptive layout settles, preventing routes from appearing over-zoomed or clipped after the sidebar changes state.
- V3 fixes remain: active temporary stops such as Kali Grogol can represent a logical stop while the regular geometry remains in the data; bottom-toolbar Info is hidden; route meta typography/gaps are aligned.

Data network geometry and K1-K10 + rail source data were otherwise not changed in this layout polish.
